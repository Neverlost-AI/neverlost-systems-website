# Neverlost Systems Website

Private source repository for the public-facing Neverlost Systems website.

## Purpose

The site introduces Neverlost Systems, Neverlost OS, and related healthcare, disability, education, and supported-decision-making work to academic, professional, and community audiences.

## Current scope

- Static, dependency-free website
- Public-safe project overview
- Links to existing demonstrations
- No private medical records, client information, internal governance, or controlled Neverlost OS materials

## Local preview

Open `index.html` in a browser. For a local web server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Deployment and the `neverlostsystems.com` domain connection will be configured after the initial content and design review.
